C++ VOLUME CALCULATOR 
__________________________________________________________________________________________________________________________________________

This is the first project in C++ where I tried to integrate:
- if, else if, and else 
- void functions
- basic syntax knowledge of C++ which I have already known

In this project, I only apply 5 volume calculations that being:
  1. Sphere calculation
  2. Tube calculation
  3. Prism with a triangle base calculation
  4. Cone calculation
  5. Block calculation

This project has taught me:
  1. How to call void functions in main(){}
  2. Planning using comments
  3. Realization that double a/b != double a.0/b.0 {otherwise it would just be declared as an integer, losing all its meaning to 1}
  4. How to use if, else if, and else in c++

Conclusion:

I had fun building this little calculator, although I am still a beginner in c++, I would like to learn some more as I progress through the language
